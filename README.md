# Jewel Coloring

宝石のドット絵パズル(Android / Kotlin、外部ライブラリなし)。

## 遊び方
- 盤面の各マスの下地の色が「正解の色」です。ジュエルを正しい色のマスへ並べ替えると絵が完成します。
- 操作は「選ぶ → 行き先をタップ」の2段階です。
  - 盤面の間違った位置のジュエルをタップすると、つながっている同色のジュエルがまとめて選ばれます。
  - トレイのジュエルをタップすると、トレイ内のその色がまとめて選ばれます。
  - 行き先に盤面の空きマスをタップすると、そこから空きマスへ順に入ります(その色の正解マスを選んだ場合は、つながった正解マスだけを埋めます)。
  - 盤面のジュエルを選んだ状態でトレイをタップすると、トレイ(65枠)へ入ります。
  - 入りきらない分は元の場所に残ります。自動で動くことはありません。
- 全マスが正しい色になればクリア。手数が少ないほど上手です。

## ビルド
- Android Studio で開いて実行、または `./gradlew assembleDebug`
- push すると GitHub Actions がテストとデバッグAPKのビルドを行い、Artifacts に `jewel-coloring-debug-apk` を保存します。

## 構成
- `Game.kt` … ルール(グループ選択・盤面/トレイへの移動・クリア判定)
- `LevelGenerator.kt` … レベルごとの対称模様と初期配置(シャッフル)の生成
- `GameView.kt` … 描画・アニメーション・タッチ操作(Canvas)
- `MainActivity.kt`
